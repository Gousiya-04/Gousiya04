## 🌟 Featured Projects

### ♿ VisionMate

Real-time indoor assistive technology designed to help visually impaired users identify household objects using Computer Vision and provide audio feedback.

**Tech:** YOLOv5 · OpenCV · Raspberry Pi · Python · Computer Vision

---

### 🧠 CareerTwin – AI Digital Twin

AI-powered digital twin that uses **LLMs, RAG, embeddings, and external tools** to provide personalized responses based on a user's profile and knowledge base.

**Tech:** LangChain · LLM · RAG · ChromaDB · Embeddings · Gradio · Python

---

### 🚦 AI Traffic Queue Analysis & Rule Violation Detection

Computer Vision-based traffic analytics system that detects and tracks vehicles from traffic videos to analyze traffic queues and identify rule violations.

**Tech:** YOLOv8 · ByteTrack / DeepSORT · OpenCV · Python · Streamlit

---

### 🌱 AgroNex / CropShield

AI-assisted agricultural decision-support platform designed to analyze crop conditions, assess risks, provide recommendations, and support expert validation.

**Tech:** Computer Vision · Machine Learning · React · AI

---

### 💧 Smart Irrigation System

IoT-based irrigation system using environmental and soil-moisture data to monitor field conditions and automate irrigation.

**Tech:** ESP32 · Soil Moisture Sensor · DHT22 · BMP085 · Blynk
